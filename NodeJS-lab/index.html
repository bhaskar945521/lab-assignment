When adding future labs (e.g. Lab-07, Lab-08), there is zero requirement to manually edit HTML, CSS, or JS files. The repository uses an automated build generator script that scans directories during deployment.

    Create new Lab folder: Add Lab-07/ inside NodeJS-lab/.
  2. 2
    Add your code & documentation: Copy from Lab-Template/, add your .js files, README.md, and terminal output in screenshots/.
  3. 3
    Push to GitHub: Netlify automatically runs npm run build (executing node scripts/generate-labs.js).
  4. 4
    Instant Portfolio Update: Netlify redeploys the updated static site with Lab-07 fully indexed, searchable, and formatted!
