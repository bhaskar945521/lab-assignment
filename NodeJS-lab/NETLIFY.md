# Netlify Deployment

This portfolio is static and can be deployed directly to Netlify. No Node server is required for the portfolio website.

1. Upload/deploy this folder to Netlify.
2. The homepage is `index.html`.
3. CSS is in `style.css` and the auto-discovery logic is in `script.js`.
4. To add Lab-07 later, create `Lab-07/lab.json` and put its files/screenshots inside `Lab-07/`. You do NOT need to edit `index.html`, `style.css`, or `script.js`.
5. The portfolio checks Lab-01 through Lab-50 for `lab.json`, so missing lab numbers are allowed.
