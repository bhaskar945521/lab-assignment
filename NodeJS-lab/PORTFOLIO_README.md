# Node.js Lab Portfolio - Direct Setup

This package is designed to be extracted DIRECTLY into your existing NodeJS-lab folder.

## Final structure
NodeJS-lab/
  portfolio-server.js
  package.json
  Lab-01/
  Lab-02/
  Lab-03/
  Lab-04/
  Lab-05/
  Lab-06/

## Run
Open terminal in NodeJS-lab and run:

    node portfolio-server.js

Then open: http://localhost:5050

## Add Lab-07 later
Create a new folder named Lab-07 inside NodeJS-lab. Add your lab files and, preferably, a lab.json. The portfolio automatically scans Lab-* folders; no HTML/JS editing is required.
